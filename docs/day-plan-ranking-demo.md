# 1日プランのランキング解説（デモ入力文）

> 今度の週末、夫婦と小学生の子ども2人の家族4人で、草津や軽井沢あたりに1泊旅行したいです。子どもたちが乗馬を体験できて、夜は家族でゆっくり温泉に入れるところがいいです。お昼は和食で。予算は1人2万円くらいでお願いします。

数値は 2026-10-14 時点の Supabase の実データで、アプリと同じ関数を使って計算したものです（楽天からの市場価格の取り直しは省略）。

---

## 全体の流れ（5段階）

1. **AIが文章を読み取る**：キーワード（草津・軽井沢・旅館・温泉・乗馬・和食）と条件（4人、宿代の予算1人2万円、宿泊あり）を取り出します。
2. **施設に点数をつける**：検索でヒットした施設（全国の約100件）それぞれに、0〜100点の「共通スコア」を出します。
3. **エリアごとにプランを組む**：午前・昼・午後・夜の枠を施設で埋めます。
4. **プランに点数をつける**：組み上がったプランごとに「プランの点」を出します。
5. **並べる**：希望エリアのプランを先にし、その中を点の高い順に並べます。

---

## ステップ2：施設の共通スコア

施設ごとに3つの観点で点をつけ、重みを掛けて足します。

| 観点         | 計算方法                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------- |
| **お得度**   | 「お得額の比率×50点＋割引率の比率×50点」。比率の基準は、検索でヒットした全施設の中での最大値（下記）        |
| **品質**     | 外部評価（★）と社員の口コミ★を混ぜて100点満点にする。口コミが多いほど社員の★の比重が上がる（10件で最大80%） |
| **条件適合** | キーワード6個のうち、その施設の情報に含まれる割合                                                           |
| **減点**     | 社員の「お得だった」回答が5割未満なら −30点                                                                 |

**共通スコア ＝ お得度×重み ＋ 品質×重み ＋ 条件適合×重み − 減点**

### お得度の「ものさし」

お得度は「いちばんお得な施設を満点として、それと比べてどれくらいか」で採点します（[ranking.py:102-109](../ranking.py#L102-L109)）。満点の基準は、**エリアに関係なく、ヒットした全施設の中から**選ばれます。

| 基準       | 値       | どの施設の値か                                 |
| ---------- | -------- | ---------------------------------------------- |
| 最大お得額 | 17,200円 | 熱海「ニューとみよし」（最もお得な料金プラン） |
| 最大割引率 | 46%      | 軽井沢「ホテルブレストンコート」               |

- 全施設が同じ17,200円と46%で割り算されるので、エリアをまたいでも点数を比べられます。
- お得額だけでなく割引率も見るのは、額だけだと料金の高い宿ほど有利になるためです。
- 基準は検索結果で変わります。希望エリアと関係のない施設（今回は熱海の宿）が目盛りを決め、点数の大きさに影響します。

### 重みづけのオプション（全3種類）

重みは [ranking.py:24-30](../ranking.py#L24-L30) で決まっていて、次の3種類があります。どの重みも、3つの合計が1.0（100%）になります。

| オプション     | お得度  | 品質    | 条件適合 | 使われる条件                                                                                          |
| -------------- | ------- | ------- | -------- | ----------------------------------------------------------------------------------------------------- |
| **① 標準**     | 40%     | 35%     | 25%      | 「施設を検索」タブでは常にこれ。1日プランでは、②③のどの語も文章にないとき                             |
| **② お得重視** | **60%** | 25%     | 15%      | 文章に「安く」「安い」「お得」「節約」「格安」「予算」のどれかがある                                  |
| **③ 品質重視** | 25%     | **50%** | 25%      | 文章に「家族」「子ども」「子供」「評判」「口コミ」「高級」「記念日」のどれかがある（②の語がないとき） |

各オプションの考え方：

- **① 標準**：3つの観点をほぼ均等に見ます。お得度をやや重くしているのは、福利厚生アプリとして「安く使えること」を基本の価値にしているためです。
- **② お得重視**：お金の話が出たら、安さを最優先します。品質と条件適合の比重は下がるので、多少評価が低くても割引の大きい施設が上に来やすくなります。
- **③ 品質重視**：家族旅行や記念日など、失敗したくない場面を想定しています。★の高い施設が上に来やすく、割引の大きさは効きにくくなります。

選び方のルール：

- 文章の中に語が**含まれているか**だけを見ます（「予算は」「お得な」のように前後に文字が付いていても当たります）。
- **②→③の順に調べ、最初に当たったもの**を使います。両方の語が入っていれば、必ず②になります。
- 重みは**1日プランのタブだけ**で切り替わります。施設を検索タブは常に①です。

### この文章で使われる重み

デモ文には「家族」「子ども」（③の語）も入っていますが、先に調べる②の「**予算**」に当たるため、**② お得重視（お得度60%・品質25%・条件適合15%）**が使われます。

## ステップ3：プランの組み立て

- エリアは最大3つです。文章にある**草津・軽井沢**を先に選び、残り1枠は共通スコアがいちばん高い施設のあるエリアにします。今回は**熱海**（ニューとみよし 74.9点）で、これは代替案になります。
- 各枠には、そのエリア・カテゴリの施設の中で**お得額がいちばん大きい施設**が入ります。共通スコアでも口コミの評価でも選びません。そのため、重みのオプションは枠の中身に影響せず、評価の低い施設も枠に入ることがあります。
- 予算2万円は**宿にだけ**当てはめます。1人3万円（予算の1.5倍）までの料金プランから選び、2万円を超えると「予算＋〇円」のバッジが付きます。
  - そのため、ステップ2の採点とプランに表示される金額は、別の料金プランになることがあります。ニューとみよしは、採点ではお得額17,200円のプランで計算されますが、プランには3万円以内のプラン（お得額9,300円）が入ります。
- 「乗馬」はどのエリアにも当たらないので、レジャー枠を周辺スポットで埋めず「自由時間」にします。熱海はヒットしたレジャー施設がないため、午前・午後とも自由時間です。

## ステップ4：プランの点（実データ）

**プランの点 ＝ 施設スコアの平均 ＋ お得額ボーナス ＋ 施設数ボーナス − 減点**

### 軽井沢プランの施設スコア

| 枠   | 施設                 | お得度 | 品質 | 適合 | 減点 | **合計** |
| ---- | -------------------- | ------ | ---- | ---- | ---- | -------- |
| 午前 | 軽井沢レイクガーデン | 30.5   | 76.0 | 16.7 | 0    | **39.8** |
| 昼   | 軽井沢 川上庵 本店   | 30.4   | 80.0 | 33.3 | 0    | **43.2** |
| 午後 | 軽井沢千住博美術館   | 30.5   | 60.0 | 16.7 | 0    | **35.8** |
| 夜   | 軽井沢つるや旅館     | 46.8   | 94.4 | 50.0 | 0    | **59.2** |

**宿の計算例：軽井沢つるや旅館**

| 項目         | 値（1人あたり） |
| ------------ | --------------- |
| 市場価格     | 27,346円        |
| 福利厚生価格 | 20,600円        |
| お得額       | 6,746円         |
| 割引率       | 約25%           |

```
お得度 ＝ 50 × (6,746 ÷ 17,200) ＋ 50 × (25 ÷ 46) ＝ 19.6 ＋ 27.2 ＝ 46.8
             ↑つるや   ↑最大お得額      ↑つるや ↑最大割引率
            のお得額  （ニューとみよし）の割引率（ホテルブレストンコート）
```

品質は外部★4.8と社員★4.6（5件で比重40%）を混ぜた★4.72で94.4点、条件適合は6語中3語（軽井沢・旅館・温泉）で50点です。
合計＝0.6×46.8 ＋ 0.25×94.4 ＋ 0.15×50 ＝ **59.2点**

### 草津プランの施設スコア

| 枠   | 施設                   | お得度 | 品質 | 適合 | 減点 | **合計** |
| ---- | ---------------------- | ------ | ---- | ---- | ---- | -------- |
| 午前 | 西の河原露天風呂       | 32.1   | 84.0 | 33.3 | 0    | **45.3** |
| 昼   | 石臼挽蕎麦 三國家      | 16.9   | 80.0 | 33.3 | −30  | **5.1**  |
| 午後 | 熱乃湯                 | 18.8   | 92.0 | 33.3 | −30  | **9.3**  |
| 夜   | 草津ナウリゾートホテル | 66.1   | 86.7 | 33.3 | 0    | **66.3** |

三國家は「お得だった」が3人中1人（33%）、熱乃湯は5人中2人（40%）で、どちらも5割を下回るため減点されています。

### プランの点

| 項目                                     | 軽井沢           | 草津            | 熱海（代替案）                             |
| ---------------------------------------- | ---------------- | --------------- | ------------------------------------------ |
| 施設スコアの平均                         | 44.5             | 31.5            | 56.8（まぐろや 38.6・ニューとみよし 74.9） |
| お得額ボーナス（500円ごとに1点、上限20） | +15.8（7,920円） | +20（12,410円） | +20（10,500円）                            |
| 施設数ボーナス                           | +10（4施設）     | +10（4施設）    | +5（2施設）                                |
| 減点（減点施設を含む）                   | 0                | −15             | 0                                          |
| **プランの点**                           | **70.3**         | **46.5**        | **81.8**                                   |

### 「減点（減点施設を含む）−15」とは

[ranking.py:144-145](../ranking.py#L144-L145) の処理です。ステップ2で −30点を受けた施設が**プランに1つでも入っていれば、一律15点**を引きます。該当施設が2つでも3つでも15点です。周辺スポットと自由時間は対象外です。

評価の低い施設は**2か所で減点**されます。草津プランでの効き方は次のとおりです。

| 段階                    | 内容                                                                    | プランの点への影響 |
| ----------------------- | ----------------------------------------------------------------------- | ------------------ |
| ステップ2（施設スコア） | 三國家・熱乃湯がそれぞれ −30。4施設の平均なので1施設あたり −7.5ずつ効く | −15                |
| ステップ4（プランの点） | 該当施設を含むので一律 −15                                              | −15                |
| **合計**                |                                                                         | **約 −30**         |

この減点がなければ、草津プランは**約76.5点**で、軽井沢（70.3点）を上回って1位でした。

## ステップ5：並べ順

- 草津・軽井沢のプランが**必ず先**に並び、その2つの間は点の高い順です → **1位 軽井沢（70.3）、2位 草津（46.5）**
- 熱海は点がいちばん高い（81.8）ものの、代替案なので**3位**です。

## デモで伝えるときのポイント

- **草津が負けたのは口コミの「お得感」のせいです**：昼と午後の施設が施設スコアで −30点ずつ、プランでもさらに −15点され、合わせて約30点下がっています。宿のお得額では草津が勝っていますが、ボーナスは上限20点で頭打ちになります。
- **枠はお得額で選ばれます**：評価の低い施設もお得額があれば枠に入り、そのあとで2回減点されます。「なぜ評判の悪い施設がプランに入っているのか」と聞かれる可能性があります。
- **お得度のものさしは全国共通です**：今回の満点の基準は熱海と軽井沢の別々の施設の値です。検索結果が変わると基準も変わり、同じ施設でも点数が変わります。
- **重みは文章の言葉で変わります**：「予算」と書いただけでお得重視になります。家族向けの品質重視にしたい場合は、予算に触れない文章にする必要があります。
- **乗馬の施設は箱根にあります**（乗馬クラブ ニューシーズン）。ただ、箱根は3つのエリア枠に入らないので、今回のプランには出ません。

⚠️ AIが予算を「1人8万円」と読み取ることが多くあります（9回中7回）。その場合は高級宿まで候補に入り、最大お得額が47,200円に上がるので、つるや旅館のお得度は46.8点から34.3点に下がります。また、キーワードが「草津温泉」になると、草津が希望エリアとして扱われません。どちらかが起きると、ランキングは上の表とは別物になります。この表はAIが正しく読み取れた場合の結果です。
